# SAYNTRA brand assets

Original geometric S monogram with two connection nodes, also used in the interface. `icon.svg` is scalable and serves as the application icon; Next.js discovers `frontend/src/app/icon.svg`. `logo-light.svg` and `logo-dark.svg` have transparent backgrounds for their named surfaces. `monochrome.svg` provides a single-ink alternative.

Wordmarks use a live Inter/Arial text fallback; convert the text to outlines in a vector editor for printing where the font is unavailable. Arabic interface typography is Tajawal, never Cairo. English is Inter. Both fonts are locally bundled through their Fontsource packages and keep the packages' original licenses.

Brand palette: Blue #3B82F6, Teal #14B8A6, Mint #2DD4BF, Purple #8B5CF6. Controls use accessible adjusted shades. Tagline: Smarter Repairs. Better Business.
